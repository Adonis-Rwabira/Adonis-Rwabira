### 2. Flagship Systems & Case Studies

#### <img src="https://cdn.simpleicons.org/googlegemini/38bdf8" width="16" height="16" align="center"/> [Muda — Neuro-Symbolic Timetabling Assistant](https://github.com/Adonis-Rwabira/Muda)
*Bachelor's Degree Thesis in Software Engineering, ULPGL*
* **Domain:** Operations Research (LLM4OR), Constraint Programming, AI Agents.
* **Core Problem:** Solving an **NP-hard** combinatorial optimization challenge tailored to operational realities in the DR Congo (double-shift rotations, fragmented part-time faculty, infrastructure deficits).
* **Architecture:** Asynchronous FastAPI orchestrator bridging LLM Gemini Flash (System 1) with Google OR-Tools CP-SAT (System 2).
* **Technical Breakthrough:** Replaced verbose JSON payloads with high-density Markdown tabular representations and ShortID mapping, shrinking context window size by **80%**.
* **Empirical Validation:** 
  * Generates and mathematically validates **1,100 weekly slots** (40 classes, 55 instructors) in **2m 16s** at an operational cost of **$0.07**.
  * Validated via a chaotic fuzzer suite achieving **100% rejection rate** of invalid state perturbations within **14.74 ms**.
* **Stack:** Python 3.11, FastAPI, OR-Tools CP-SAT, Redis SSE & Distributed Lock, PostgreSQL (JSONB), React 18, Jotai, TailwindCSS.

#### <img src="https://cdn.simpleicons.org/dotnet/38bdf8" width="16" height="16" align="center"/> AntiMayundo — Systems Security & Memory Forensics Tool
*Autonomous Systems Utility in C#*
* **Incident Response:** Engineered to eradicate the rapid outbreak of the "Mayundo" computer worm propagating across USB drives at the ULPGL campus.
* **Execution:** Scanned and terminated malicious resident memory processes, cleaned system registry hooks, and recursively reverted corrupted, hidden file attributes.

* **Stack:** C#, .NET Runtime, Win32 API, FileSystem Forensics.
